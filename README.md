CarShop Mobile

Aplicativo desenvolvido em React Native como Projeto Integrador da disciplina de Desenvolvimento Mobile.

Sobre o Projeto

O CarShop Mobile simula um catálogo digital de veículos para uma concessionária.

O usuário pode:

- Visualizar catálogo de carros
- Filtrar por marca
- Ajustar faixa de preço
- Navegar pelas informações da loja
- Visualizar detalhes dos veículos

---

Tecnologias Utilizadas

- React Native
- JavaScript
- Expo
- FlatList
- Picker
- Slider
- ScrollView
- SafeAreaView

---

Funcionalidades

 SafeAreaView

Proteção da interface em dispositivos modernos.

ScrollView

Seção "Sobre a Loja" com conteúdo rolável.

 Picker

Filtro de marcas:

- BMW
- Audi
- Toyota
- Honda

Slider

Filtro de preço:

- R$ 50.000
- até
- R$ 500.000

FlatList

Listagem dinâmica de veículos contendo:

- Imagem
- Nome
- Preço
- Descrição
